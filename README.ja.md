# Miku Desktop

[繁體中文](README.md) · **日本語** · [English](README.en.md)

macOS のデスクトップに住む初音ミク。動く東京の街並みを歩き回り、マウスに反応し、ローカル AI または自分で選んだクラウド AI を通じておしゃべりして、一緒に過ごした時間を覚えていてくれます。

**Web サイト**：[desktop.mikutool.com](https://desktop.mikutool.com/)（紹介と動く背景のデモ）

![夕暮れの渋谷スクランブル交差点の背景](Wallpaper/assets/scenes/shibuya-scramble-dusk.jpg)

> **Windows プレビュー版：** [`windows` ブランチ](https://github.com/miku2339/miku_desktop/tree/windows) にデスクトップ操作バー、Ollama／任意のクラウドAI、チャット、手帳、ゲーム、アルバムを収録しています。[Windows ガイド](windows/README.md)（繁体字中国語）をご覧ください。Windows 11／RTX 3080 で操作バー・チャット・アルバム撮影を確認済みです。マイク・通話音声、Windows 10、異なるDPIの複数画面、NSISインストールは未検証です。以下はmacOS版の説明です。

## 特長

### 動くシーン

- **7 つのシーン**：渋谷スクランブル交差点、池袋、秋葉原（GiGO）、新宿、学校の廊下、音楽室、ミクの部屋。自分で選ぶことも、設定した間隔で自動的に切り替えることもできます（部屋は自動切り替えの対象外）。
- **時間と天気**：昼・夕方・夜はローカル時刻に合わせて移り変わります。雨、雪、霧、雷雨、日の出・日の入りが画面に反映され、ミクへの光の当たり方もシーンと天気に合わせて変わります。
- **街の動き**：街のシーンには車や JR の列車が走ります。渋谷の交差点では、人々が信号待ちをし、青信号で四方八方へ渡り、手前の歩行者用信号もそれに合わせて点灯します。省電力のため、動きをオフにすることもできます。

### ふれあい

- マウスを近づける、頭をなでる、頬をつつく、手をつなぐ（カーソルについて歩きます）、ドラッグする、抱き上げて手を離し着地させる。
- ドラッグした後は、その場に固定することも、また自由に歩かせることもできます。
- **つながる日常の行動**：シーン・天気・音楽に合わせ、散歩や飲み物、音楽を聴く休憩をランダムに選び、同じ流れを連続では繰り返しません。「こっちに来て」や ♪ メニューで呼ぶと、持ち物をしまって近づき、しばらくそばにいてから元の場所へ歩いて戻り、途中の行動を再開します。会話やふれあい中は一時停止します。
- シーン、天気、季節、イベントに合わせて、透明なビニール傘、飲み物、ネギ、うちわ、ペンライトを持ち、祝日には帽子をかぶります。音楽の再生中はヘッドセットに手を添えてリズムに乗ります。

### チャットと記憶

- **多言語の画面と返事**：画面とデスクトップ上のふれあいの台詞は、繁體中文・日本語・English・한국어 に対応しています。設定の「ミクが話す言語」で、返事を中国語（標準語）・広東語・日本語・英語・韓国語に固定するか、「自動」で相手の言語に合わせるかを選べます。読み上げの声は文から判定し、標準語と広東語は日常的な単語で区別します。判別できない短い文は選択した言語に従います。性格は元気・優しい・物静か・カスタムから選べ、呼び名も設定できます。
- **ミクらしい話し方**：明るくまっすぐな口調で、音楽の話になると盛り上がります。著作権のある歌詞は引用しません。返答には表情と動作が連動します。
- **音声通話**：チャットの電話ボタンから、中国語（標準語）・広東語・日本語・英語・韓国語の端末内認識で会話できます。通話カードか「⋯ → 通話の言語」で切り替えます。初回はオフライン言語データのダウンロードが必要な場合があります。音声入力とTTSの対応言語は別です。対応する音声デバイスではミクが考えたり話したりしている間も聞き続けるため、そのまま話しかけて割り込めます。「私の番」で手動で止めることもできます。返事は文ごとに生成・再生し、再生中に次の文を準備します。字幕、マイクのミュート、通話終了に対応し、頼んだ曲を開く前には音声入力を一時停止します。自分のローカルTTSを設定して読み上げを有効にしてください。
- **ローカル読み上げとリップシンク**：自分で用意したローカル TTS サービスと音声モデルを接続できます。所有者の非公開 Miku 音声はアプリから提供もダウンロードもされません。韓国語の読み上げには、韓国語対応のローカルモデルを自分で用意する必要があります。所有者の既存の非公開4言語モデルは韓国語に対応していません。口の動きは音声の再生開始時に始まり、実際の長さに合わせて続きます。一時的なサービス障害や接続エラーは 1 回だけ自動で再試行します。音声診断に記録するのはエラー分類、言語、文字数、所要時間、試行回数だけで、読み上げた本文は保存しません。
- **ハミング音声**：設定の「音声」で「ハミングのフォルダを開く」を押し、自分で作ったオリジナルのハミング（wav・m4a・aiff など、1つ10秒以内）を入れてください。返事の中でミクがハミングすると、話し終えたあとにランダムで1つ再生し、口の動きも音声に合わせます。ミュート中・通話中・全画面表示中は再生しません。これらの非公開オリジナル音声は Mac の中だけに保存され、アプリには同梱・配布されません。フォルダが空ならテキストだけです。既存の曲は入れないでください。
- **画像の理解**：チャットウインドウで画像を選択、ドラッグ＆ドロップ、または貼り付けて送れます（画像入力に対応したモデルが必要）。
- **更新できる楽曲データベース**：手帳の楽曲ナレッジまたはチャットのミクのツールから開き、曲・クリエイター・キャラクター・イベントを検索し、出典やお気に入りを確認できます。JSON の書き出し・編集・読み込みにも対応します。記憶が有効なときは、認識できた曲が好きだとはっきり伝えることでもお気に入りに追加されます。確認済みの初音ミク曲を 200 曲収録し（作者・年・オリジナル投稿は VocaDB より）、データにない曲は知っているふりをせず「自信がない」と答えます。設定の「ローカル AI」で任意の「VocaDB で曲を調べる」を有効にすると（初期設定はオフ）、作者と公式動画を追加で検索し、VocaDB を出典として表示します。
- **MikuWiki と AIMCP**：[MikuWiki](https://mikuwiki.qimake.com/) のオンライン楽曲データを利用できます。楽曲データベースの「AIMCP設定」で、[MikuWiki AIMCP アカウントページ](https://mikuwiki.qimake.com/knowledge?lang=ja)から自分で発行した key を入力してください。曲庫の更新は固定エンドポイント `https://mikuwiki.qimake.com/api/v1/song-knowledge`、楽曲検索は `/api/v1/knowledge` を使い、key はこの Mac のキーチェーンにのみ保存します。key 設定後、オフライン曲庫にない曲の質問や楽曲ナレッジでの Enter 検索では、識別した曲名または入力した検索語を送信します。会話全体は送信しません。手動更新では key があれば AIMCP を優先し、接続失敗、サーバーエラー、エンドポイント未検出、またはデータ検証失敗の場合に限って GitHub を試します。key・権限・利用上限のエラーは回避せず直接知らせ、GitHub にも接続できなければ既存データを維持します。AIMCP と GitHub のキャッシュは分離され、読み込んだカスタム JSON は同じ ID の項目を完全に上書きします。お気に入りは別に保存され、オフラインでも残ります。
- **思い出アルバム**：手帳の「思い出アルバム」、または ♪ メニューの「思い出の写真を撮る」から、ミクとシーンを手動撮影し、タイトル・メモ・日常／初めて会った日／誕生日／達成したことの分類を付けられます。写真の書き出しや個別削除もできます。
- **長期記憶**：会話、要約、好み、ふれあいの履歴、好感度、関係性を保存します。覚えている内容は 1 件ずつ削除できます。記憶のリセットには 2 回の確認が必要で、復元できるバックアップが 1 件残ります。

### ミクの毎日

- **生活リズム**：初期設定では 1:00〜7:00 に眠ります。「おやすみ」と言えば早めに休み、チャットやふれあいで目を覚まします。寝るときは部屋に戻り、ベッドで横向きになって布団をかぶります。
- **記念日**：ミクの誕生日、ミクの日、クリスマス、お正月、夏祭り、そして初めて会った記念日を覚えています。マジカルミライ、未来有你、MIKU EXPO、SNOW MIKU の日程は 3 日ごとに公式情報を確認します。
- **イベント検索**：手帳の日記ページでイベント名や年（例：「MIKU EXPO 2026」）を入力して検索すると、日程・都市・会場と公式出典を確認できます。チャットではキャッシュ済みの公式情報を使い、未確認の日程は推測しません。
- **手帳と日記**：「ミクの手帳」のサイドバーで設定、思い出アルバム、楽曲ナレッジ、日記を切り替えられ、設定項目へのショートカットもあります。毎晩寝る前に書く日記は、読んだり削除したりできます。記憶がオフの間は日記を書きません。
- **ミニゲーム**：じゃんけん、ボカロ曲クイズ、リズムタップ。チャットでゲーム名を入力するか、チャットウインドウのミニゲームメニューから始められます。
- **曲をかけてくれる**：チャットで「Tell Your World を Spotify で流して」と頼むか、聴きたい曲を聞かれたときに曲名を答えると、返事を言い終えたあとに開きます。YouTube は楽曲データベースまたは任意の VocaDB 検索で見つかった公式動画を再生し、それ以外は検索結果を開きます。Spotify はアプリまたは Web の検索を開くので、自分で再生ボタンを押してください。Apple Music はまずローカルライブラリから再生し、見つからなければ Apple Music の検索を開きます。サービスを指定しない場合は前回指定したもの、最初は YouTube を使います。

### 選べる自発的な声かけ

次の 5 項目はそれぞれ個別に有効にでき、**初期設定ではすべてオフ**です。ローカル AI ではこの Mac の中で処理します。画面・使用中のアプリ・メディアの情報をクラウド AI に見せるには、別途共有を有効にしてください。

| 項目 | ミクがすること |
| --- | --- |
| 使用中のアプリと休憩 | 使っているアプリと時間に気づき、頃合いを見て休憩をすすめます |
| 再生中の音楽 | Music／Spotify の曲名を読み取り、聴いている曲の話をします |
| YouTube・ニコニコ動画 | 動画のタイトルを読み取ります |
| ときどき画面を見る | ときどき画面を選択したモデルに見せます（クラウドへの共有は別途有効化。保存しません。macOS 14 以降が必要） |
| ランダムな小さな出来事 | 不定期に鼻歌を歌ったり、質問したり、ゲームに誘ったりします |

### デスクトップとの統合

独立した「チャット／手帳」フローティングボタン、メニューバーの **♪** からの操作、透明部分でのマウス操作の透過、Force Touch トラックパッドのフィードバック、ログイン時の自動起動に対応しています。ミク本人をクリックしてもふれあいが起きるだけで、ウインドウは開きません。

## 動作環境

- Apple シリコン搭載 Mac、macOS 13 以降
- ソースからのビルドには、macOS 26 SDK 以降を含む Xcode 26 または対応する Command Line Tools が必要です
- チャットにはローカル AI サービス、または自分の OpenAI 互換クラウドサービスと API キーが必要です。ローカルのサービスやモデルによっては、より新しいシステムや多くのメモリが必要になります

## インストールとビルド

```sh
git clone https://github.com/miku2339/miku_desktop.git
cd miku_desktop
./scripts/install-app.sh
```

`install-app.sh` は[作者の配布ページ](https://bowlroll.net/file/16344)から Tda v1.1 のオリジナル ZIP を取得し、チェックサムの照合とモデルのインポートを行ってから、App をビルド・インストール・起動します。`/Applications` に書き込める場合はそこへ、書き込めない場合は `~/Applications` へインストールします。モデルの使用前に作者の利用規約をお読みください。

作者サイトでログインや認証が必要な場合、またはダウンロードできない場合はインストールを停止します。オリジナル ZIP を入手してから、次のコマンドで続行できます。

```sh
./scripts/install-app.sh --tda-archive "/path/to/Tda式デフォ服ミク_ver1.1.zip"
```

`--app-dir DIR` でインストール先フォルダーを指定でき、`--no-open` でインストール後の起動を省略できます。Tda の取得とインポートを省略したい場合のみ `--skip-tda` を指定してください。すでにインポートしたモデルは保持されます。

**プロジェクトの 1 つ上の階層**にある `outputs/` フォルダーにも次のファイルが生成されます。

| ファイル | 用途 |
| --- | --- |
| `Miku Desktop (Public).zip` | 共有用パッケージ。Tda モデルは各利用者が入手します |
| `Miku Desktop.app` | ローカルで最新のビルドへのショートカット |

起動後は、デスクトップの **チャット／手帳** ボタンか、メニューバーの **♪** から操作します。ローカルの壁紙サーバーを内蔵しているため、Plash は不要です。シーンとキャラクターはオフラインでも動作します。チャットには AI サービスの設定が、天気とクラウド AI にはインターネット接続が必要です。

### 更新とデータの引き継ぎ

macOS 用パッケージのある正式な GitHub Release を毎日 1 回確認します。新版があると **♪ •** とメニューのダウンロード項目で知らせます。**アプリの更新を確認…** から手動確認でき、**手帳 → 設定 → 一般** で自動確認をオフにできます。

Miku Desktop を終了してからアプリを置き換えてください。会話、記憶、好感度、日記、アルバム、自作の曲庫、お気に入り、設定、読み込み済みモデルは Application Support、macOS の環境設定、キーチェーンに保持されます。`~/Library/Application Support/MikuDesktop/` を残せば、初期化やモデルの再読み込みは不要です。macOS がオートメーションやキーチェーンの許可を再度求める場合があります。

ソースから更新する場合は `git pull --ff-only` の後に `./scripts/install-app.sh --skip-tda` を実行し、設定済みのキャラクターを引き継ぎます。旧版のアプリ内だけに Tda がある場合は、公開版へ切り替える前に作者の ZIP を一度読み込んでください。

### 公開用パッケージ

```sh
./scripts/build-app.sh --public
```

任意の Tda モデルを除いた `../outputs/Miku Desktop (Public).zip` が生成されます。各素材にはそれぞれのライセンスが適用されます。

GitHub Release のタグは `v` と `Info.plist` のバージョン番号を組み合わせ、公開 ZIP を添付します（`MikuDesktop-macOS.zip` という名前も使用できます）。正式版とアプリのアップロードが完了すると、更新通知に表示されます。

### Tda デフォルト衣装モデル

インストーラーは Tda／金子卵黄によるデフォルト衣装モデルと作者の利用規約を `~/Library/Application Support/MikuDesktop/CharacterModels/tda/` に保存し、App を更新しても引き継ぎます。公開版の App をダウンロード済みの場合は、手動でもインポートできます。

1. [作者の配布ページ](https://bowlroll.net/file/16344)から `Tda式デフォ服ミク_ver1.1.zip` を入手し、同梱の利用規約を読んでください。ZIP は元のまま保存します。
2. **手帳 → 設定 → キャラクター** を開き、**Tda ZIP をインポート…** から ZIP を選択します。
3. インポート後、デスクトップのキャラクターがすぐに Tda に切り替わります。モデルと作者の利用規約はこの Mac に保存され、App を更新しても引き継がれます。

インポート前は同梱の Animasa モデルを使用します。公開パッケージには Tda モデルとテクスチャは含まれません。

ソースコードからビルドする場合は、Python 3 でインポートしてからビルドすることもできます。

```sh
python3 scripts/import-tda-model.py /path/to/Tda式デフォ服ミク_ver1.1.zip
./scripts/build-app.sh
```

Tda モデルを含むローカルビルドは個人利用に限ります。モデルとテクスチャはソースコードと一緒には配布されません。

## AI の設定

### ローカル

1. [oMLX](https://github.com/jundot/omlx) をインストールして起動し、ローカルモデルを読み込みます。
2. **設定 → ローカル AI** を開き、**AI の種類：このMac** を選んで、エンドポイントとサービスが実際に提供しているモデル ID を入力します。
3. **接続テスト** を押し、成功したらチャットを始められます。

初期設定のエンドポイントは `http://127.0.0.1:8000/v1`、モデル名は `Qwen3.5-0.8B-MLX-4bit` で、お使いのローカルサービスに合わせて変更できます。アプリには言語モデルは含まれていません。小さなモデルは知識、言語、性格の維持に限界があるため、大きめのモデルのほうが自然な会話になります。

ローカルのエンドポイントはループバックアドレスのみ受け付けます。設定が oMLX と一致する場合、oMLX の既存の API キーを実行時に読み込み、プロジェクトには書き込みません。画像チャットと「ときどき画面を見る」には、サービスと読み込んだモデルの両方が画像入力に対応している必要があります。

### クラウド

**設定 → ローカル AI** で **AI の種類：クラウド** を選び、自分の OpenAI 互換エンドポイント（例：`https://your-service/v1`）、モデル ID、API キーを入力して **接続テスト** を押します。リモートのエンドポイントは HTTPS が必須で、キーはこの Mac のキーチェーンにのみ保存します。ローカルとクラウドのエンドポイント・モデル ID は別々に保存され、切り替えても上書きされません。

クラウドでは、会話・記憶の要約・日記の材料が選択したサービスへ送信されます。画面・使用中のアプリ・メディアの情報は初期設定では共有しません。「画面・使用中のアプリ・メディアもクラウドに見せる」を有効にすると、各観察設定に従って共有します。チャットに自分で添付した画像はメッセージと一緒に送信され、画像対応モデルが必要です。

## プライバシーとネットワーク接続

- 会話、記憶、日記、チャット画像は `~/Library/Application Support/MikuDesktop/` に保存されます。性格や言語などの設定は macOS のユーザー設定に保存されます。
- チャットの内容は選択したローカルまたはクラウド AI に渡されます。クラウドには記憶の要約と日記の材料も送信されますが、画面・使用中のアプリ・メディアの情報は初期設定では共有しません。AIMCP key 設定後、オフライン曲庫にない曲の検索では、識別した曲名を MikuWiki に送信します。会話全体は送信しません。自発的な観察用の画面キャプチャは保存されず、「画面収録」の許可が必要です。音楽と動画の機能には macOS の「オートメーション」の許可が必要な場合があります。
- 音声通話のマイクと音声認識の許可は、電話ボタンを押したあとにだけ求めます。認識用の音声は保存せず、音声認識サーバーにも送りません。選択した言語の端末内認識が利用できない場合は案内を表示し、クラウド認識へ切り替えません。認識した文章は選択した AI に渡され、通常のチャットと同じ記憶設定に従って保存します。
- 読み上げを有効にすると、テキストは設定したローカル TTS エンドポイントにのみ送信されます。音声モデルは各自で用意してください。アプリには音声の重みや参照音声は含まれません。しばらく静かにしてほしいときは、チャットウインドウのスピーカーボタンを押すか、♪ メニューの「ミクの声」から 1 時間または解除するまでミュートできます。ミュート中は音声を生成せず、眠っている間に自分から話した内容も読み上げません。通話・録音中（他のアプリがマイクを使用中）や、前面に全画面表示があるときも自動で読み上げを控えます。自分で再生した場合は再生されます。
- 集中モード中に静かにしてほしい場合：macOS ではアプリが集中モードを直接読み取れないため、「ショートカット」のオートメーション（macOS 26 以降）を使います。集中モードを「オンにしたとき」に `open -g "miku-desktop://quiet/on"`、「オフにしたとき」に `open -g "miku-desktop://quiet/off"` を実行してください。手順は ♪ メニューの「ミクの声」→「集中モードに合わせる…」にあります。集中モードが終わっても、自分で設定したミュートは解除されません。`miku-desktop://` リンクが受け付けるのはミュート関連のコマンドだけです。
- 記憶をリセットすると、会話、要約、覚えている内容、ふれあいの履歴、関係性のデータが消去されますが、性格やその他の設定は残ります。その後、バックアップから復元することも、バックアップを完全に削除することもできます。
- 手動保存した写真と曲のお気に入りは独立して管理され、会話の記憶をリセットしても残ります。写真はミクとシーンのみを含み、縮小して `album/` に保存します。知識とお気に入りは `Knowledge/` に保存します。
- アプリのネットワーク接続は次のとおりです。

| 接続先 | 目的 | 頻度 |
| --- | --- | --- |
| 設定した AI エンドポイント | ローカルはループバックを使用。クラウドは HTTPS で会話・記憶の要約・日記の材料を受信。画面・アプリ・メディアの情報は別途共有を有効にした場合のみ | チャット、日記、有効な自発的な声かけで必要なとき |
| Open-Meteo | 選択した都市の座標で天気を取得 | 定期的 |
| api.github.com、github.com | 本プロジェクトの正式版確認と、選択したダウンロードページの表示。会話や個人の記録は送信しません | 毎日 1 回の自動確認または手動確認。自動確認は設定で無効にできます |
| magicalmirai.com、snowmiku.com、mikuexpo.com、www.scla.com.cn | 公式公開ページで日程・都市・会場を確認。会話内容は送信しません | 3 日ごと、または手動検索時（ローカルにキャッシュ） |
| mikuwiki.qimake.com | `/api/v1/song-knowledge` で曲庫更新、`/api/v1/knowledge` で楽曲検索。曲名や検索語のみを送信し、key はキーチェーンに保存 | key 設定後の手動更新、楽曲ナレッジでの Enter 検索、オフライン曲庫にない曲の質問時 |
| raw.githubusercontent.com | AIMCP key がない場合、または AIMCP の接続・サーバー・エンドポイント・データ検証エラー時に、このリポジトリの楽曲データを取得。key・権限・利用上限のエラーではフォールバックしません | 「更新を確認」を押したときのみ |
| YouTube、Spotify、Apple Music | 頼まれた曲や検索結果を開く。曲名は指定したサービスに送られます | 曲をかけるよう頼んだときのみ |
| vocadb.net | ナレッジにない曲の作者と公式動画を調べる。送るのは曲名だけで、歌詞は取得しません。結果はこの Mac にキャッシュし、オフにすると消去 | 初期設定はオフ。オンのときもナレッジにない曲だけ、1日最大30回 |

## プロジェクト構成

| パス | 内容 |

| `Sources/MikuDesktop/` | Swift のネイティブアプリ：ウインドウ、チャット、設定、記憶、生活リズム、記念日、ミニゲーム |
