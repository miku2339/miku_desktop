# Miku Desktop

[繁體中文](README.md) · **日本語** · [English](README.en.md)

macOS のデスクトップに住む初音ミク。動く東京の街並みを歩き回り、マウスに反応し、Mac の中で動くローカル AI を通じておしゃべりして、一緒に過ごした時間を覚えていてくれます。

**Web サイト**：[miku.qimake.com](https://miku.qimake.com/)（紹介と動く背景のデモ）

![夕暮れの渋谷スクランブル交差点の背景](Wallpaper/assets/scenes/shibuya-scramble-dusk.jpg)

## 特長

### 動くシーン

- **7 つのシーン**：渋谷スクランブル交差点、池袋、秋葉原（GiGO）、新宿、学校の廊下、音楽室、ミクの部屋。自分で選ぶことも、設定した間隔で自動的に切り替えることもできます（部屋は自動切り替えの対象外）。
- **時間と天気**：昼・夕方・夜はローカル時刻に合わせて移り変わります。雨、雪、霧、雷雨、日の出・日の入りが画面に反映され、ミクへの光の当たり方もシーンと天気に合わせて変わります。
- **街の動き**：街のシーンには車や JR の列車が走ります。渋谷の交差点では、人々が信号待ちをし、青信号で四方八方へ渡り、手前の歩行者用信号もそれに合わせて点灯します。省電力のため、動きをオフにすることもできます。

### ふれあい

- マウスを近づける、頭をなでる、頬をつつく、手をつなぐ（カーソルについて歩きます）、ドラッグする、抱き上げて手を離し着地させる。
- ドラッグした後は、その場に固定することも、また自由に歩かせることもできます。
- シーン、天気、季節、イベントに合わせて、透明なビニール傘、飲み物、ネギ、うちわ、ペンライトを持ち、祝日には帽子をかぶります。音楽の再生中はヘッドセットに手を添えてリズムに乗ります。

### チャットと記憶

- **3 言語対応**：繁體中文、日本語、English。性格は元気・優しい・物静か・カスタムから選べ、呼び名も設定できます。
- **ミクらしい話し方**：明るくまっすぐな口調で、音楽の話になると盛り上がります。著作権のある歌詞は引用しません。返答には表情、動作、口の動きが連動します。
- **画像の理解**：チャットウインドウで画像を選択、ドラッグ＆ドロップ、または貼り付けて送れます（画像入力に対応したローカルモデルが必要）。
- **長期記憶**：会話、要約、好み、ふれあいの履歴、好感度、関係性を保存します。覚えている内容は 1 件ずつ削除できます。記憶のリセットには 2 回の確認が必要で、復元できるバックアップが 1 件残ります。

### ミクの毎日

- **生活リズム**：初期設定では 1:00〜7:00 に眠ります。「おやすみ」と言えば早めに休み、チャットやふれあいで目を覚まします。寝るときは部屋に戻り、ベッドで横向きになって布団をかぶります。
- **記念日**：ミクの誕生日、ミクの日、クリスマス、お正月、夏祭り、そして初めて会った記念日を覚えています。マジカルミライと SNOW MIKU の日程は 3 日ごとに公式サイトで確認します。
- **手帳と日記**：毎晩寝る前に日記を書き、「ミクの手帳」で読んだり削除したりできます。記憶がオフの間は日記を書きません。
- **ミニゲーム**：じゃんけん、ボカロ曲クイズ、リズムタップ。チャットでゲーム名を入力するか、チャットウインドウのミニゲームメニューから始められます。

### 選べる自発的な声かけ

次の 5 項目はそれぞれ個別に有効にでき、**初期設定ではすべてオフ**です。処理はすべてこの Mac の中で行われます。

| 項目 | ミクがすること |
| --- | --- |
| 使用中のアプリと休憩 | 使っているアプリと時間に気づき、頃合いを見て休憩をすすめます |
| 再生中の音楽 | Music／Spotify の曲名を読み取り、聴いている曲の話をします |
| YouTube・ニコニコ動画 | 動画のタイトルを読み取ります |
| ときどき画面を見る | ときどき画面をローカルモデルに見せます（保存しません。macOS 14 以降が必要） |
| ランダムな小さな出来事 | 不定期に鼻歌を歌ったり、質問したり、ゲームに誘ったりします |

### デスクトップとの統合

独立した「チャット／設定」フローティングボタン、メニューバーの **♪** からの操作、透明部分でのマウス操作の透過、Force Touch トラックパッドのフィードバック、ログイン時の自動起動に対応しています。ミク本人をクリックしてもふれあいが起きるだけで、ウインドウは開きません。

## 動作環境

- Apple シリコン搭載 Mac、macOS 13 以降
- Xcode Command Line Tools（Swift 5.10 以降）
- チャットには別途ローカル AI サービスが必要です。サービスやモデルによっては、より新しいシステムや多くのメモリが必要になります

## インストールとビルド

```sh
git clone https://github.com/miku2339/miku_desktop.git
cd miku_desktop
./scripts/fetch-model.sh
./scripts/build-app.sh
```

`fetch-model.sh` はキャラクターモデルをダウンロードし、チェックサムを照合します。使用前にモデルに付属する利用規約をお読みください。

ビルド結果は**プロジェクトの 1 つ上の階層**にある `outputs/` フォルダーに出力されます。

| ファイル | 用途 |
| --- | --- |
| `Miku Desktop.zip` | 展開して、App を「アプリケーション」フォルダーに移動して起動します |
| `Miku Desktop.app` | ローカルで最新のビルドへのショートカット |

起動後は、デスクトップの **チャット／設定** ボタンか、メニューバーの **♪** から操作します。ローカルの壁紙サーバーを内蔵しているため、Plash は不要です。シーンとキャラクターはオフラインでも動作します。チャットにはローカル AI サービスが、天気にはインターネット接続が必要です。

### 公開用パッケージ

```sh
./scripts/build-app.sh --public
```

任意の Tda モデルを除いた `../outputs/Miku Desktop (Public).zip` が生成されます。各素材にはそれぞれのライセンスが適用されます。

### 任意：Tda クラシック衣装モデル

Tda／金子卵黄によるクラシック衣装モデルを使う場合は、[作者の配布ページ](https://bowlroll.net/file/16344)から `Tda式デフォ服ミク_ver1.1.zip` を入手し、同梱の規約を読んだうえで Python 3 でインポートしてください。

```sh
python3 scripts/import-tda-model.py /path/to/Tda式デフォ服ミク_ver1.1.zip
./scripts/build-app.sh
```

インポートしない場合は Animasa モデルを使用します。Tda モデルを含むビルドは個人利用に限ります。モデルとテクスチャはソースコードと一緒には配布されません。

## ローカル AI の設定

1. [oMLX](https://github.com/jundot/omlx) をインストールして起動し、ローカルモデルを読み込みます。
2. **設定 → ローカル AI** を開き、エンドポイントと、サービスが実際に提供しているモデル ID を入力します。
3. **接続テスト** を押し、成功したらチャットを始められます。

初期設定のエンドポイントは `http://127.0.0.1:8000/v1`、モデル名は `Qwen3.5-0.8B-MLX-4bit` で、お使いのローカルサービスに合わせて変更できます。アプリには言語モデルは含まれていません。小さなモデルは知識、言語、性格の維持に限界があるため、大きめのモデルのほうが自然な会話になります。

安全のため、エンドポイントはループバック（ローカル）アドレスのみ受け付けます。設定が oMLX と一致する場合、oMLX の既存の API キーを実行時に読み込み、プロジェクトには書き込みません。画像チャットと「ときどき画面を見る」には、サービスと読み込んだモデルの両方が画像入力に対応している必要があります。

## プライバシーとネットワーク接続

- 会話、記憶、日記、チャット画像は `~/Library/Application Support/MikuDesktop/` に保存されます。性格や言語などの設定は macOS のユーザー設定に保存されます。
- チャットの内容と、有効にした項目で得た情報は、ローカル AI にだけ渡されます。画面のキャプチャは保存されず、「画面収録」の許可が必要です。音楽と動画の機能には macOS の「オートメーション」の許可が必要な場合があります。
- 記憶をリセットすると、会話、要約、覚えている内容、ふれあいの履歴、関係性のデータが消去されますが、性格やその他の設定は残ります。その後、バックアップから復元することも、バックアップを完全に削除することもできます。
- アプリが自ら接続するのは次のサイトだけです。

| 接続先 | 目的 | 頻度 |
| --- | --- | --- |
| Open-Meteo | 選択した都市の座標で天気を取得 | 定期的 |
| magicalmirai.com、snowmiku.com | 公開ページを読み込み、マジカルミライと SNOW MIKU の日程を確認 | 3 日ごと（結果はローカルにキャッシュ） |

## プロジェクト構成

| パス | 内容 |
| --- | --- |
| `Sources/MikuDesktop/` | Swift のネイティブアプリ：ウインドウ、チャット、設定、記憶、生活リズム、記念日、ミニゲーム |
| `Wallpaper/companion/` | キャラクター（three.js／MMD）、動く背景、人の流れと車、ふれあい |
| `Wallpaper/assets/scenes/` | シーン画像とレイアウトデータ |
| `Tests/` | JavaScript と Swift のテスト |
| `scripts/` | ビルド、モデルのダウンロード、テスト用スクリプト |
| `website/`、`deploy/website/` | Web サイトのソースとデプロイ設定 |

## 開発とテスト

変更後は次のチェックを実行できます（JavaScript のテストには Node.js が必要です）。

```sh
node --test Tests/*.test.mjs
./scripts/test-memory.sh
./scripts/test-relationship.sh
./scripts/test-awareness.sh
./scripts/test-sleep-schedule.sh
./scripts/test-special-days.sh
./scripts/test-mini-games.sh
```

Issue や Pull Request を歓迎します。問題を報告する際は、macOS のバージョン、再現手順、関連する画面を添えてください。ログを共有する前に、個人的な会話、API キー、その他の個人情報を取り除いてください。
