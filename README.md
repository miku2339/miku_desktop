# Miku Desktop

**繁體中文** · [日本語](README.ja.md) · [English](README.en.md)

住在 macOS 桌面上的初音未來：她會在動態的東京街景裡走動、回應你的滑鼠，也能透過在本機執行的 AI 和你聊天，並記住你們的相處。

**網站**：[miku.qimake.com](https://miku.qimake.com/)（介紹與動態背景示範）

![黃昏的澀谷十字路口背景](Wallpaper/assets/scenes/shibuya-scramble-dusk.jpg)

## 特色

### 會動的場景

- **七個場景**：澀谷十字路口、池袋、秋葉原（GiGO）、新宿、校園走廊、音樂教室，以及 Miku 的房間。可以手動選擇，或依設定的間隔自動輪換（房間不參與輪換）。
- **時間與天氣**：日間、黃昏、夜晚隨本機時間漸變；雨、雪、霧、雷雨與日出日落都會反映在畫面上，角色的光線也會跟著場景與天氣改變。
- **街上的動態**：街景有車流與 JR 列車；澀谷十字路口有路人等紅燈、綠燈時從四面八方穿越，近處的行人號誌也會跟著亮燈。動態效果可以關閉以節省電力。

### 和她互動

- 滑鼠靠近、摸頭、戳臉、牽手（她會跟著游標走）、拖曳、抱起來再放手讓她落地。
- 拖曳後可以把她固定在原位，也可以讓她重新自由走動。
- **連貫日常**：依場景、天氣與音樂隨機安排散步、喝飲料或聽歌，不會連續重複同一套活動。輸入「過來一下」或使用 ♪ 選單，她會先收起道具、走近停留，再走回去接續原本的活動；聊天與觸碰會暫停流程。
- 依場景、天氣、季節與活動拿透明雨傘、飲料、大蔥、扇子或螢光棒，節日會戴帽子；播放音樂時會扶著耳機跟著節拍擺動。

### 聊天與記憶

- **多語介面與回覆**：介面和桌面互動台詞支援繁體中文、日本語、English、한국어。在設定的「Miku 說話的語言」可以固定她用國語、粵語、日語、英語或韓語回覆，或選「自動」跟著你用的語言；朗讀會依文字判斷語言，國語與粵語以常用詞區分；短句無法分辨時採用所選語言。性格可選活潑、溫柔、安靜或自訂，也能設定她怎麼稱呼你。
- **像她本人的說話方式**：語氣開朗直率，聊到音樂會興奮起來；不會引用有版權的歌詞。回覆會配合表情與動作。
- **語音通話**：在聊天視窗按電話按鈕，可選國語、粵語、日語、英語或韓語的本機辨識；在通話卡片或「⋯ → 通話語言」切換。首次使用可能需要下載所選語言的離線資源，收音語言與 TTS 聲線支援分開。支援的音訊裝置上，Miku 思考或說話時仍持續收聽，你可以直接開口插話；也可按「輪到我說」手動打斷。回覆按完整句子依序產生與播放，下一句可在前一句播放時準備。提供即時字幕、麥克風靜音及結束通話；開啟要求的歌曲前會先暫停收音。需啟用並設定自己的本機 TTS。
- **本機朗讀與嘴形**：可接入你自己提供的本機 TTS 服務與語音模型；App 不提供或下載擁有者的私人 Miku 聲線。韓語朗讀需自行提供支援韓語的本機模型；擁有者現有的四語私人模型不支援韓語。音訊開始播放時嘴形才會啟動，並跟隨實際音訊長度；遇到暫時性的服務或連線錯誤會自動重試一次。語音診斷只記錄錯誤類型、語言、字數、耗時與嘗試次數，不保存朗讀文字。
- **哼歌片段**：在設定的「語音」按「打開哼唱資料夾」，放入你自己做的原創哼唱（wav、m4a、aiff 等，每段 10 秒內）。她在回覆裡哼歌時，會唸完回覆後隨機播放一段，嘴形跟著音訊動；靜音、通話或全螢幕時不播放。這些私人原創片段只留在本機，不會隨 App 散布；資料夾是空的就只顯示文字。請勿放入現有歌曲。
- **看得懂圖片**：在聊天視窗選取、拖放或貼上圖片（需要支援圖片輸入的本機模型）。
- **可更新的歌曲知識庫**：從手帳的「歌曲知識庫」或聊天視窗的「陪伴工具」開啟，搜尋歌曲、P 主、角色與活動資料、查看來源、標記喜歡的歌，也可匯出、編輯及匯入 JSON。開啟記憶時，明確表達喜歡某首已識別的歌曲也會加入收藏。內建 200 首查證過的初音未來歌曲（作者、年份與原版連結取自 VocaDB）；知識庫沒有的歌，她會說自己不確定，不會假裝知道。也可在設定的「本機 AI」開啟選用的「向 VocaDB 查歌」（預設關閉），額外查詢作者與官方影片並標示來源。
- **MikuWiki 與 AIMCP**：[MikuWiki](https://mikuwiki.qimake.com/) 提供線上歌曲知識。在歌曲知識庫的「AIMCP 設定」填入你自己於 [MikuWiki AIMCP 帳戶頁](https://mikuwiki.qimake.com/knowledge?lang=zh-TW)產生的 key；App 透過固定端點 `https://mikuwiki.qimake.com/api/v1/song-knowledge` 更新曲庫，並以 `/api/v1/knowledge` 查歌；key 僅存於這部 Mac 的鑰匙圈。設定 key 後，聊天問到離線曲庫沒有的歌曲，或在歌曲知識庫按 Enter 查詢時，會傳送辨識出的歌名或你輸入的查詢文字，不會傳送整段聊天。手動檢查更新時，有 key 會優先使用 AIMCP；只有連線失敗、服務端錯誤、端點不存在或資料驗證失敗時才改試 GitHub。key、權限或額度錯誤會直接提示，不會靜默回退；GitHub 也無法使用時則保留現有資料。AIMCP 與 GitHub 使用分開的快取，自訂 JSON 仍會完整覆蓋同 ID 條目，收藏則獨立保存並可離線使用。
- **共同回憶相簿**：從手帳的「回憶相簿」開啟，或從 ♪ 選單選「拍下回憶照片」，手動拍下目前的 Miku 與場景，加入標題、小記及日常／初次見面／生日／一起完成的事分類。可匯出照片或逐張刪除。
- **長期記憶**：保存對話、摘要、偏好、互動記錄、好感度與關係狀態；記得的事可以逐條刪除。重設記憶需要確認兩次，並保留一份可以復原的備份。

### 她的日常

- **作息**：預設 01:00–07:00 睡覺。說晚安可以讓她早點休息，聊天或互動會把她叫醒。睡覺時會回到房間，側躺在床上蓋好棉被。
- **節日與紀念日**：記得 Miku 生日、Miku Day、聖誕節、新年、夏日祭典，以及你們第一次見面的紀念日。魔法未來、未來有你、MIKU EXPO 與 SNOW MIKU 的日期每 3 天從官方來源確認一次。
- **活動查詢**：在手帳的日記頁輸入活動名稱或年份（例如「MIKU EXPO 2026」），按「查詢」更新官方日程；可查看日期、城市、場地與來源。聊天也能詢問這些活動，使用已快取的官方資料；未確認的日期不會猜測。
- **手帳與日記**：「Miku 的手帳」用側邊欄切換設定、回憶相簿、歌曲知識庫與日記，並提供設定分段捷徑。她每晚睡前寫一篇日記，可以閱讀或刪除；記憶關閉時不寫日記。
- **小遊戲**：猜拳、Vocaloid 歌曲問答與打拍子。在聊天輸入遊戲名稱，或從聊天視窗的小遊戲選單開始。
- **幫你播歌**：在聊天說「幫我用 Spotify 播 Tell Your World」，或在她問你想聽哪首時直接回答歌名，她回覆並唸完後就會打開。YouTube 會直接播放歌曲知識庫或選用 VocaDB 查到的官方影片，否則打開搜尋結果；Spotify 會開啟 App 或網頁搜尋，由你按下播放；Apple Music 會先嘗試播放本機資料庫裡的歌曲，找不到時打開 Apple Music 搜尋。沒說平台時沿用上次說過的，預設是 YouTube。

### 選擇性主動陪伴

以下五項可以個別開啟，**預設全部關閉**，而且只在這台 Mac 上處理：

| 項目 | 她會做什麼 |
| --- | --- |
| 使用中的 App 與作息 | 留意你在用什麼、用了多久，適時提醒休息 |
| 正在播放的音樂 | 讀取 Music／Spotify 的歌名，聊聊你在聽的歌 |

| 定時看看畫面 | 偶爾把畫面交給本機模型看（不存檔，需要 macOS 14 以上） |
| 隨機小事件 | 不定時哼歌、問你問題、找你玩遊戲 |

### 桌面整合

獨立的「聊天／手帳」浮動按鈕、選單列 **♪** 控制、透明區域滑鼠穿透、支援 Force Touch 觸控板回饋，以及登入時自動啟動。點 Miku 本身只會觸發角色互動，不會誤開視窗。

## 系統需求

- Apple silicon Mac，macOS 13 以上
- 從原始碼建置需 Xcode 26 或對應的 Command Line Tools，包含 macOS 26 SDK 或更新版本
- 聊天功能需要另外執行本機 AI 服務；服務與模型可能需要更新的系統或更多記憶體

## 安裝與建置

```sh
git clone https://github.com/miku2339/miku_desktop.git
cd miku_desktop
./scripts/install-app.sh
```

`install-app.sh` 預設從[作者配布頁](https://bowlroll.net/file/16344)取得 Tda v1.1 原始 ZIP、核對校驗碼並匯入模型，再建置、安裝及開啟 App。可寫入 `/Applications` 時會安裝到該處，否則使用 `~/Applications`。使用模型前請閱讀原作者規約。

若作者網站要求登入、驗證或無法下載，安裝會停止。自行取得原始 ZIP 後可接續安裝：

```sh
./scripts/install-app.sh --tda-archive "/path/to/Tda式デフォ服ミク_ver1.1.zip"
```

可用 `--app-dir DIR` 指定安裝資料夾，或以 `--no-open` 完成安裝後暫不開啟。只有希望略過 Tda 取得與匯入時才使用 `--skip-tda`；已匯入的模型會保留。

安裝時也會在**專案上一層**的 `outputs/` 資料夾產生：

| 檔案 | 用途 |
| --- | --- |
| `Miku Desktop (Public).zip` | 可分享的安裝包，Tda 模型由各使用者自行取得 |
| `Miku Desktop.app` | 指向本機最新建置的捷徑 |

開啟後，用桌面上的 **聊天／手帳** 按鈕或選單列的 **♪** 操作。程式內建本機桌布伺服器，不需要 Plash。場景與角色可以離線運作；聊天需要本機 AI 服務，天氣需要網路。

### 公開分享用的打包

```sh
./scripts/build-app.sh --public
```

會產生 `../outputs/Miku Desktop (Public).zip`，並排除選用的 Tda 模型。各項素材仍適用各自的授權條款。

### Tda 經典服裝模型

安裝程式會把 Tda／金子卵黄的經典服裝模型與原作者規約存入 `~/Library/Application Support/MikuDesktop/CharacterModels/tda/`，更新 App 後仍會保留。已下載公開版 App 的使用者也可手動匯入：

1. 從[作者的配布頁](https://bowlroll.net/file/16344)下載 `Tda式デフォ服ミク_ver1.1.zip`，閱讀包內的使用規約，保留原始 ZIP。
2. 開啟 **手帳 → 設定 → 角色**，按 **匯入 Tda ZIP…**，選取該壓縮檔。
3. 匯入完成後，桌面角色會立即切換成 Tda。模型與原作者的規約保存在這部 Mac，更新 App 後仍會保留。

匯入前會使用內附的 Animasa 模型。公開安裝包不包含 Tda 模型與貼圖。

從原始碼建置時，也可用 Python 3 匯入後再建置：

```sh
python3 scripts/import-tda-model.py /path/to/Tda式デフォ服ミク_ver1.1.zip
./scripts/build-app.sh
```

這種包含 Tda 模型的本機建置只限自己使用。模型與貼圖不會隨原始碼散布。

## 設定本機 AI

1. 安裝並啟動 [oMLX](https://github.com/jundot/omlx)，載入一個本機模型。
2. 打開 **設定 → 本機 AI**，填入端點與服務實際提供的模型 ID。
3. 按 **測試連線**，成功後就可以開始聊天。

預設端點是 `http://127.0.0.1:8000/v1`，模型名稱是 `Qwen3.5-0.8B-MLX-4bit`，可依你的本機服務修改。程式本身不附帶語言模型；小模型在知識、語言與維持性格上的能力有限，換用較大的模型效果會更好。

為了安全，端點只接受 loopback 位址（本機）。設定與 oMLX 一致時，程式會在執行時讀取 oMLX 既有的 API key，不會寫進專案。圖片聊天與「定時看看畫面」需要服務與載入的模型都支援視覺輸入。

## 隱私與網路連線

- 對話、記憶、日記與聊天圖片存放在 `~/Library/Application Support/MikuDesktop/`；性格、語言等偏好存放在 macOS 使用者設定。
- 聊天內容與你開啟的觀察資料交給本機 AI；設定 AIMCP key 後，缺少離線資料的歌曲查詢會另外把辨識出的歌名送至 MikuWiki，完整對話不會送出。主動觀察的畫面擷取不會存檔，需要「螢幕錄製」權限；音樂與影片功能可能需要 macOS「自動化」權限。
- 語音通話只在你按下電話按鈕後要求麥克風與語音辨識權限。辨識音訊不存檔，也不送往辨識伺服器；所選語言的本機辨識未就緒時會提示，不會改用雲端辨識；離線語言資源由 macOS 下載與管理。辨識出的文字同一般聊天，依記憶設定保存。
- 啟用朗讀後，文字只會送往設定的本機 TTS 端點。語音模型需自行提供，安裝包不包含語音權重或參考音訊。想暫時安靜時，可按聊天視窗的喇叭按鈕，或在 ♪ 選單的「Miku 的聲音」選擇靜音 1 小時或直到取消；靜音期間不會產生語音，她入睡時主動說的話也不會朗讀。正在通話或錄音（其他 App 使用麥克風）、或前景有全螢幕畫面時，也會自動暫停朗讀；你手動重播的仍會播放。
- 想在專注模式時讓她安靜：macOS 不允許 App 直接讀取專注模式，可改用「捷徑」的自動化（macOS 26 以上）。在專注模式「開啟時」執行 `open -g "miku-desktop://quiet/on"`、「關閉時」執行 `open -g "miku-desktop://quiet/off"` 即可；詳細步驟見 ♪ 選單「Miku 的聲音」→「跟隨專注模式…」。專注模式結束只會取消它自己的靜音，不會取消你手動設定的靜音。`miku-desktop://` 連結只接受靜音相關指令。
- 重設記憶會清除對話、摘要、記得的事、互動記錄與關係資料，但保留性格與其他設定。之後可以用備份復原，或永久刪除備份。
- 手動相簿與歌曲收藏獨立保存，可在手帳的對應頁面管理；重設對話記憶不會刪除。照片只包含 Miku 與場景，縮小後儲存在 `album/`；知識與收藏存放在 `Knowledge/`。
- 程式的網路連線如下：

| 連線對象 | 用途 | 頻率 |
| --- | --- | --- |
| Open-Meteo | 用所選城市的座標查詢天氣 | 定期 |
| magicalmirai.com、snowmiku.com、mikuexpo.com、www.scla.com.cn | 讀取活動官方公開頁面，確認日期、城市與場地；不傳送聊天內容 | 每 3 天或手動查詢，結果快取在本機 |
| mikuwiki.qimake.com | 透過 `/api/v1/song-knowledge` 更新曲庫、以 `/api/v1/knowledge` 查歌；只送出歌名或曲庫查詢文字，使用你自行產生並存於鑰匙圈的 key | 設定 key 後，手動更新、曲庫按 Enter 查詢，或聊天問到離線曲庫沒有的歌曲時 |
| raw.githubusercontent.com | 沒有 AIMCP key，或 AIMCP 發生連線、服務端、端點或資料驗證錯誤時，下載此專案維護的歌曲知識資料；key、權限或額度錯誤不會回退 | 僅手動按「檢查更新」時 |
| YouTube、Spotify、Apple Music | 打開你要求播放的歌曲或搜尋結果，歌名會送往你指定的服務 | 僅在你要求播歌時 |
| vocadb.net | 查詢知識庫沒有的歌曲作者與官方影片，只送出歌名，不取得歌詞；結果快取在本機，關閉時清除 | 預設關閉；開啟後只在問到或要播知識庫沒有的歌時，每日最多 30 次 |
