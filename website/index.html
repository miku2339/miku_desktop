現在是你所在地的白天

Miku 住在你的桌面

日出、黃昏、深夜，她的房間會隨著你的時鐘變換光線。你可以摸摸頭、牽手、和她聊天；她會記得你說過的事。

不只是一張桌布

她會在桌面上走來走去。滑鼠靠近時，她會看過來；戳戳臉、摸摸頭，她都會有反應。拖曳她時可以把她提起，放手後她會回到地面。

凌晨一點左右，她會回房、側躺上床並蓋好棉被。你也可以對她說晚安，讓她提早入睡。

下雨天她會撐透明雨傘，下午茶時間會端著飲料，有時還會搧扇子、抱著大蔥或揮螢光棒；節日會戴上應景的帽子。你播音樂時，她會扶著耳機跟著節拍擺動。

七個場景，三種時間

澀谷十字路口、池袋、秋葉原、新宿、校園走廊、音樂教室，以及 Miku 的房間。在澀谷，路人會在路口等紅燈，綠燈一亮就從四面八方穿越；街景會下雨、下雪，也有車輛與 JR 列車經過。若想節省電力，可以關閉動態效果。

聊天，而且記得你

今天好累

辛苦了～要不要讓我哼一首輕快的歌陪你？♪

  • 三種語言。繁體中文、日本語、English。中文預設以台灣國語的口吻回覆，想聽粵語可以直接跟她說。
  • 像她本人。個性開朗直率，一聊到音樂就停不下來；她會哼歌，但不會引用有版權的歌詞。
  • 可以選擇個性。活潑、溫柔、安靜，或者自行撰寫，再設定她如何稱呼你。
  • 長期記憶。她會記住你的喜好與你們之間的關係，也可以逐條刪除她記得的事情。
  • 看得懂圖片。把圖片拖進聊天視窗即可，但本機模型必須支援圖片輸入。

她的每一天

  • 節日與紀念日。她記得自己的生日、Miku Day、聖誕節、新年和夏日祭典，也記得你們第一次見面的日子。魔法未來與 SNOW MIKU 的日期每 3 天從官方網站確認一次。
  • 手帳與日記。每晚睡前，她會把今天的事寫進日記，你可以在「Miku 的手帳」裡翻閱。
  • 小遊戲。猜拳、Vocaloid 歌曲問答、跟著節拍打拍子，在聊天裡說一聲就能開始。
  • 偶爾主動找你。開啟「隨機小事件」後，她會不定時哼歌、問你問題，或找你一起玩。

全部留在你的 Mac

聊天由你電腦上的 AI 模型處理，對話、記憶和圖片都不會上傳。天氣功能只會傳送所選城市的座標；確認魔法未來與 SNOW MIKU 的日期時，只會讀取官方網站的公開頁面。

留意你正在使用的 App、正在聽的歌曲、正在看的影片、定時看看畫面，以及隨機小事件，這五項主動陪伴功能預設全部關閉，必須由你逐項開啟。

安裝

  1. 下載原始碼並建置

    依照 GitHub 建置指引 clone 倉庫，再執行 ./scripts/fetch-model.sh 及 ./scripts/build-app.sh。

  2. 允許開啟

    第一次開啟時 macOS 可能會阻擋。前往「系統設定 → 隱私權與安全性」，按「仍要打開」。

  3. 準備本機 AI

    安裝並啟動 oMLX，載入一個模型。預設是 Qwen3.5-0.8B；如果記憶體足夠，較大的模型會有更好的對話表現。

  4. 連線，開始聊天

    按一下選單列的 ♪，進入「設定 → 本機 AI」，再按「測試連線」。場景和角色不需要 AI 也能使用。
