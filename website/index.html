不只是一張桌布

她會在桌面上走來走去。滑鼠靠近時，她會看過來；戳戳臉、摸摸頭，她都會有反應。拖曳她時可以把她提起，放手後她會回到地面。

凌晨一點左右，她會回房、側躺上床並蓋好棉被。你也可以對她說晚安，讓她提早入睡。

七個場景，三種時間

澀谷、池袋、秋葉原、新宿、校園走廊、音樂教室，以及 Miku 的房間。街景會下雨、下雪，也有車輛與 JR 列車經過；若想節省電力，可以關閉動態效果。

全部留在你的 Mac

聊天由你電腦上的 AI 模型處理，對話、記憶和圖片都不會上傳。天氣功能只會傳送所選城市的座標。

查看你正在使用的 App、正在聽的歌曲、正在看的影片，以及定時理解畫面，這四項主動陪伴功能預設都關閉，必須由你逐項開啟。

安裝

  1. 下載原始碼並建置

    依照 GitHub 建置指引 clone 倉庫，再執行 ./scripts/fetch-model.sh 及 ./scripts/build-app.sh。

  2. 允許開啟

    第一次開啟時 macOS 可能會阻擋。前往「系統設定 → 隱私權與安全性」，按「仍要打開」。

  3. 準備本機 AI

    安裝並啟動 oMLX，載入一個模型。預設是 Qwen3.5-0.8B；如果記憶體足夠，較大的模型會有更好的對話表現。

  4. 連線，開始聊天

    按一下選單列的 ♪，進入「設定 → 本機 AI」，再按「測試連線」。場景和角色不需要 AI 也能使用。
