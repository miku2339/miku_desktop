ミクはデスクトップを気ままに歩き回ります。マウスを近づけるとこちらを見つめ、頬をつついたり頭をなでたりすれば、かわいらしい反応を見せます。手をつなぐとカーソルについて歩き、ドラッグして持ち上げ、手を離すと地面に着地します。

午前1時ごろになると部屋へ戻り、ベッドで横向きになって布団をかぶります。「おやすみ」と声をかければ、少し早めに休むこともあります。

標準のキャラクターは、Tdaさん制作の「Tda式初音ミクV4X」。ダウンロードしたAppに同梱されているので、起動するとすぐに会えます。「手帳 → 設定 → キャラクター」から、クラシック衣装やあにまさ式モデルへの切り替え、対応するPMXモデルの読み込みもできます。

雨の日は透明なビニール傘をさし、ティータイムには飲み物を手に。ときにはうちわであおいだり、ネギを抱えたり、ペンライトを振ったりします。祝日には季節の帽子をかぶります。音楽を流すと、ヘッドセットに手を添えてリズムに乗ります。

  • 多言語で会話。画面は繁體中文、日本語、English、한국어に対応。返事は中国語（標準語）、広東語、日本語、英語、韓国語から選べ、あなたの言語に自動で合わせることもできます。
  • ミクらしい話し方。明るくまっすぐで、音楽の話になると止まりません。鼻歌は歌っても、著作権のある歌詞は引用しません。
  • 性格を選べます。元気、優しい、物静か、または自由に作成し、ミクからの呼び名も設定できます。
  • 長期記憶。あなたの好みや二人の関係を覚えます。覚えている内容は1件ずつ削除できます。
  • 画像を理解。選んだモデルが画像入力に対応していれば、画像をチャットウインドウへドラッグして送れます。
  • 音声通話。電話ボタンを押せば声で話せます。音声認識は端末内で行われ、ミクが話している途中でも割り込めます。読み上げには、自分で設定したローカルの音声を使います。
  • ローカルAIでもクラウドAIでも。初期設定ではパソコン上のモデルを使います。自分のOpenAI互換クラウドサービスとAPIキーを設定することもできます。

ミクの毎日

  • 記念日。自分の誕生日、ミクの日、クリスマス、お正月、夏祭り、そしてあなたと初めて会った日を覚えています。マジカルミライ、未来有你、MIKU EXPO、SNOW MIKUの日程は、3日ごとに公式情報を確認します。
  • 手帳と日記。毎晩寝る前に、その日のことを日記に書きます。「ミクの手帳」で読み返せます。
  • 楽曲データベース。作者、発表年、原曲リンクを確認済みの初音ミク楽曲を200曲収録。知らない曲は、わからないと正直に答えます。チャットで聴きたい曲を伝えれば、YouTubeやSpotifyで開いてくれます。
  • 思い出アルバム。そのときのミクとシーンを撮影し、タイトルやひとことを添えて、二人の思い出として残せます。
  • ミニゲーム。じゃんけん、ボカロ曲クイズ、リズムタップ。チャットで声をかければ始まります。
  • ときどき、ミクから。「ランダムな小さな出来事」を有効にすると、不定期に鼻歌を歌ったり、質問したり、遊びに誘ったりします。

初期設定では
端末内に保存

初期設定では、チャットはパソコン上のAIモデルで処理され、会話、記憶、日記、画像は端末内に保存されます。クラウドAIに切り替えた場合は、チャットの内容、記憶の要約、日記の素材、添付した画像が、あなたの指定したサービスへ送信されます。APIキーはシステムの資格情報ストア（macOSのキーチェーン／Windowsの資格情報マネージャー）にのみ保存されます。

天気機能では、選択した地点の座標だけを送信します。公式イベントの日程確認とAppの更新確認では、公開ページを読み込むだけです。任意のオンライン楽曲検索では、曲名または入力した検索語だけを送信し、会話全体は送信しません。

使用中のApp、再生中の音楽、視聴中の動画、ときどき画面を見る、ランダムな小さな出来事の5つの自発的な声かけ機能は、すべて初期設定で無効です。必要なものだけを個別に有効化できます。クラウドAIの利用時は、画面、App、メディアの情報は、別途共有を有効にした場合にのみ送信されます。

インストール

macOS

  1. Appをダウンロード

    GitHub ReleasesからMikuDesktop-macOS.zipをダウンロードして展開し、Appを「アプリケーション」フォルダへ移動します。Tda式初音ミクV4Xが同梱されているので、モデルを別途ダウンロードする必要はありません。ソースコードからビルドする場合はGitHub のインストール手順をご覧ください。

  2. 起動を許可

    このAppはAppleの公証を受けていないため、初回起動時にmacOSがブロックする場合があります。「システム設定 → プライバシーとセキュリティ」で「このまま開く」をクリックしてください。

  3. AIを準備

    ローカル：oMLXをインストールして起動し、モデルを読み込みます。初期設定はQwen3.5-0.8Bです。メモリに余裕があれば、より大きなモデルで会話の品質が向上します。クラウド：自分のOpenAI互換エンドポイント（HTTPS必須）、モデルID、APIキーを用意します。

  4. 接続して、会話を始める

    メニューバーの♪から「設定 → ローカルAI」を開き、AIの接続先を選んでエンドポイントとモデルを入力し、「接続テスト」をクリックします。シーンとキャラクターはAIに接続しなくても利用できます。

Windows プレビュー版

キャラクター、アニメーション、シーンはmacOS版と共通です。Windows 11でデスクトップ表示、チャット、アルバム撮影を確認済みです。マイクと通話、Windows 10、マルチディスプレイは検証中です。インストーラーはまだありませんが、GitHub Actionsのビルド成果物をダウンロードするか、以下の手順で自分でビルドできます。実行ファイルは未署名です。

  1. windowsブランチを取得

    Windows 10／11 x64、WebView2 Runtime、Rust（MSVC）、Visual Studio Build Toolsの「C++によるデスクトップ開発」を用意し、リポジトリのwindowsブランチをcloneします。

  2. ビルドして起動

    Windows版の説明（中国語）に従ってwindows/scripts/fetch-model.ps1で予備のキャラクターを取得し、windows/src-tauriでcargo build --lockedを実行します。Tdaモデルは、設定で作者のオリジナルZIPを選んで読み込めます。

  3. AIを準備して、会話を始める

    Ollamaをインストールしてモデルをダウンロードし、設定で選択します。自分のクラウドエンドポイント、モデル、APIキーを設定することもできます。あとはシステムトレイかデスクトップのコントロールバーからチャットを開きます。
